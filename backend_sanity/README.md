# Huy Portfolio - Sanity Backend

This is the Sanity CMS backend for the portfolio website.

## Development

To start the Sanity Studio development server:

```bash
npm run dev
```

To deploy the Sanity Studio:

```bash
npm run deploy
```

## Schema

The backend includes a `works` schema for managing portfolio projects with fields for:
- Title
- Description
- Project Link
- Code Link
- Image
- Tags (Data Analysis, Machine Learning, Others)
